# Base Project

Переиспользуемый шаблон приложения на FastAPI, PostgreSQL, Vue 3, PrimeVue 4, Pinia и Vue Router.

## Что включено

- регистрация, вход и профиль пользователя;
- JWT-аутентификация и ролевая модель доступа;
- управление пользователями, ролями и разрешениями;
- загрузка файлов с ограничением размера и allowlist расширений;
- персональная история загрузок;
- скачивание и удаление собственных файлов;
- административный просмотр всех файлов;
- адаптивный layout и светлая/тёмная тема.

Предметная логика намеренно отсутствует. Добавляйте новые модули через отдельные модели, API-router, Pinia store и Vue-view.

## Быстрый запуск

```bash
cp .env.example .env
# замените SECRET_KEY и параметры PostgreSQL
uv sync
uv run alembic upgrade head
uv run uvicorn main:app --reload --port 8000
```

Во втором терминале:

```bash
cd frontend
cp .env.example .env.development
npm ci
npm run dev
```

Frontend откроется на `http://localhost:5173`, API — на `http://localhost:8000/api`.

## Первый администратор

После регистрации назначьте пользователю роль `admin`:

```bash
uv run python scripts/promote_user.py admin@example.com
```

Шаблон не создаёт администратора с паролем по умолчанию.

## Безопасность файлов

- оригинальное имя не используется как путь на диске;
- файл получает случайное UUID-имя;
- размер проверяется во время потоковой записи;
- пользователь видит только собственные файлы;
- администратор может просматривать общий каталог;
- `ALLOWED_EXTENSIONS=[]` разрешает любые расширения — для production задайте явный список.
