# Руководство по расширению BaseProject

## Базовый контур

Шаблон владеет пользователями, ролями, разрешениями и файловым хранилищем. Предметные модули не должны дублировать эти сущности: они связываются с `users.id` и при необходимости с `files.id`.

## Backend-модуль

1. Добавьте SQLAlchemy-модель в `app/dbapi/models`.
2. Экспортируйте её из `app/dbapi/models/__init__.py`.
3. Создайте Pydantic-схемы в `app/schemas`.
4. Добавьте router в `app/api` и подключите его в `main.py` под `settings.API_PREFIX`.
5. Защитите операции через `CurrentUser` или `require_permission("domain.action")`.
6. Создайте Alembic-миграцию и добавьте новые разрешения явным seed-блоком.

## Frontend-модуль

1. Создайте Pinia store для серверного состояния.
2. Создайте Vue-view с loading, error и empty states.
3. Добавьте маршрут с `meta.permission` или `meta.roles`.
4. Добавьте пункт меню в `AppLayout.vue`.
5. Используйте существующие semantic-классы и PrimeVue, не дублируйте цветовые значения в компонентах.

## UI-система

- основной акцент: teal;
- навигация: тёмно-синий operational shell;
- поверхности: белые в светлой теме и сине-графитовые в тёмной;
- радиусы: 8–14 px в зависимости от уровня компонента;
- шаг отступов: 4 px;
- адаптивные точки обязательной проверки: 320, 768, 1024 и 1440 px;
- интерактивные элементы должны иметь доступное имя и работать с клавиатуры.

## Правила безопасности

- разрешения проверяются на backend, route guard служит только UX-фильтром;
- внешние идентификаторы нельзя превращать в путь к файлу;
- персональные ресурсы всегда фильтруются по `current_user.id`;
- новые расширения файлов добавляются в явный allowlist;
- секреты задаются только через `.env`, который исключён из Git;
- admin-роль назначается явной deployment-командой, стандартного пароля нет.
